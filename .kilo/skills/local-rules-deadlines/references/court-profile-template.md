# Court profile (template)

Copy this file into the matter's own folders (not into the kit) and fill it for the court that will hear the matter. Fill each value only from a primary source and record the URL and date checked. Leave a value blank and mark it UNVERIFIED until it is checked. Re-check before each filing.

The matter profile (`Legal_Kit/matter_profile.template.json`, field `court_profile_path`) records where the filled copy lives.
