# Privilege Log — Common Fields and Samples

## Typical Required Fields
(Verify against the court’s local rule or standing order.)

| Field | Description | Example |
|-------|-------------|---------|
| Doc ID / Bates | Unique identifier or range | PRIV-001 or Bates 00045–00047 |
| Date | Date of document | 2024-03-12 |
| Author | Person who created it | J. Smith, Esq. |
| Recipient(s) | Persons who received it | Client A; co-counsel B |
| Document Type | Email, memo, letter, note, etc. | Email |
| Privilege Claimed | Attorney-client, work product, etc. | Attorney-client |
| Factual Basis | Non-privileged description of why privilege applies | Communication seeking legal advice regarding response to subpoena |
| Notes | Redaction needed, third-party issue, further review, etc. | Partial; redact ¶¶ 3–4 |

## Cautions
- Basis column must not reveal the advice or the content of the communication.
- List every recipient. Presence of a non-privileged third party is a common waiver issue.
- Partially privileged documents should be noted for redaction rather than full withholding when possible.
- Update the log if documents are later produced or if the claim is withdrawn.
